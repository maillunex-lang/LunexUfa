# Дорожная карта LunexUfa

Клиент собираем только для Android. Разработка и проверки идут на Windows через Terminal/RDP. Сервер и веб-админку сначала проверяем локально, целевая среда — Ubuntu VPS. Эталон — Darklord (`Baseline/Darklord-Android` и при необходимости `C:\SOURCE\Darklord-Final`). Владелец разрешил прямой доступ на запись. Код вести в `Client`, `Server`, `Admin` внутри `C:\SOURCE\LunexUfa`.

**Порядок продукта (согласовано с владельцем):** не «все карты подряд» и не «только меню без мира». Сначала вертикальный цикл **логин → сервер → герой → Haitan → квест**, затем добивка геймплея/2 клиентов, затем следующие локации партиями.
