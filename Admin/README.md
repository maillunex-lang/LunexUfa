# Русская веб-админка LunexUfa (локальный прототип)

Открывает второй мир, меняет цену товара, запускает бота. API — локальный `Server` на порту 8080.

## Запуск

1. Сервер: `python C:\SOURCE\LunexUfa\Server\run_server.py`
2. Админка: `python C:\SOURCE\LunexUfa\Admin\run_admin.py`
3. Браузер: `http://127.0.0.1:8090`
